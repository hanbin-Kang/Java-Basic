# Java 객체지향 프로그래밍(OOP) 기초

## 1. 객체지향 프로그래밍(OOP)

객체지향 프로그래밍(Object-Oriented Programming)이란 기존 프로그래밍 언어에 객체지향 개념과 규칙을 추가하여 프로그램을 객체 단위로 구성하는 프로그래밍 방식이다.

### 객체지향 프로그래밍의 장점

1. **코드의 재사용성이 높다.**
   - 상속을 통해 기존 코드를 활용하여 새로운 코드를 쉽게 작성할 수 있다.

2. **코드의 관리가 용이하다.**
   - 코드 간의 관계를 이용하여 적은 노력으로 코드를 변경하고 관리할 수 있다.

3. **신뢰성이 높은 프로그래밍이 가능하다.**
   - 제어자와 메서드를 이용하여 데이터를 보호하고(캡슐화), 올바른 값을 유지할 수 있다.
   - 코드의 중복을 제거하여 코드 불일치로 인한 오동작을 방지할 수 있다.

### 객체지향 프로그래밍의 핵심 개념

1. 캡슐화(Encapsulation)
2. 상속(Inheritance)
3. 추상화(Abstraction)
4. 다형성(Polymorphism)

## 2. 클래스와 객체

### 클래스(Class)

- **정의:** 객체를 정의해 놓은 것.
- **용도:** 객체를 생성하는 데 사용한다.
- 서로 관련된 데이터와 기능을 하나로 묶은 구조이다.

### 객체(Object)

- **정의:** 실제로 존재하는 사물 또는 개념.
- **용도:** 객체가 가지고 있는 속성과 기능에 따라 달라진다.

### 객체의 구성 요소

객체는 속성과 기능으로 구성된다.

| 구성 요소 | 설명 | Java에서의 표현 |
|---|---|---|
| 속성(Property) | 객체가 가지고 있는 데이터 | 변수 |
| 기능(Function) | 객체가 수행할 수 있는 동작 | 메서드 |

### 클래스 작성 예시

```java
class TV {
    // 속성(변수)
    String color;
    boolean power;
    int channel;

    // 기능(메서드)
    void power() {
        power = !power;
    }

    void channelUp() {
        channel++;
    }

    void channelDown() {
        channel--;
    }
}
```

위 클래스는 TV 객체가 가질 속성과 기능을 정의한 것이다.

### 객체 생성과 사용

```java
TV t;
t = new TV();
```

- `TV t;` : TV 객체를 참조하기 위한 참조변수 선언.
- `new TV();` : TV 클래스의 인스턴스 생성.
- `t` : 생성된 객체의 주소를 저장하는 참조변수.

객체 생성과 참조변수 선언을 한 번에 작성할 수도 있다.

```java
TV t = new TV();
```

### 객체 사용

```java
t.channel = 7;  // 객체의 변수 사용
t.channelDown(); // 객체의 메서드 사용
```

객체의 속성은 `참조변수.변수명`, 기능은 `참조변수.메서드명()`으로 사용한다.

### 객체 배열

객체 배열은 여러 객체의 주소를 저장할 수 있는 참조변수 배열이다.

```java
TV[] tvArr = new TV[3];

tvArr[0] = new TV();
tvArr[1] = new TV();
tvArr[2] = new TV();
```

주의할 점은 `new TV[3]`만으로 TV 객체 3개가 생성되는 것은 아니라는 것이다.

참조변수 3개가 만들어지며, 각각의 객체는 별도로 생성해야 한다.

## 3. 클래스의 또 다른 정의

### (1) 데이터와 함수의 결합

클래스는 데이터와 함수를 결합한 구조이다.

| 구분 | 설명 |
|---|---|
| 변수 | 하나의 데이터를 저장하는 공간 |
| 배열 | 같은 종류의 여러 데이터를 하나의 집합으로 저장하는 공간 |
| 구조체 | 서로 관련된 여러 데이터를 종류에 관계없이 하나의 집합으로 저장하는 공간 |
| 클래스 | 데이터와 함수를 결합한 구조(구조체 + 함수) |

### (2) 사용자 정의 타입

클래스는 사용자가 직접 새로운 데이터 타입을 정의할 수 있도록 한다.

```java
class Time {
    int hour;
    int minute;
    float second;
}

Time t = new Time();
```

`Time`이라는 사용자 정의 타입을 만들었으며, `t`는 생성된 객체의 주소를 저장하는 참조변수이다.

## 4. 변수의 종류

변수는 선언 위치에 따라 크게 세 가지로 구분된다.

### 변수의 종류

| 구분 | 선언 위치 | 생성 시점 | 특징 |
|---|---|---|---|
| 인스턴스 변수(iv) | 클래스 영역 | 인스턴스 생성 시 | 객체마다 독립적으로 존재 |
| 클래스 변수(cv) | 클래스 영역 | 클래스가 메모리에 로딩될 때 | 모든 객체가 공유 |
| 지역 변수(lv) | 메서드, 생성자, 초기화 블럭 내부 | 변수 선언문 실행 시 | 해당 영역에서만 사용 가능 |

### 클래스 작성 예시

```java
class MyClass {
    // 인스턴스 변수
    int iv;

    // 클래스 변수
    static int cv;

    void method() {
        // 지역 변수
        int lv = 0;
    }
}
```

### (1) 인스턴스 변수

- 인스턴스가 생성될 때 만들어진다.
- 객체마다 독립적인 값을 가진다.
- 사용하려면 객체를 먼저 생성해야 한다.
- 예시: 포커 카드의 무늬와 숫자.

### (2) 클래스 변수

- `static` 키워드를 사용한다.
- 클래스가 메모리에 로딩될 때 생성된다.
- 모든 인스턴스가 하나의 변수를 공유한다.
- 객체 생성 여부와 관계없이 사용할 수 있다.
- 예시: 포커 카드의 가로 길이와 세로 길이.

### (3) 지역 변수

- 메서드 내부 등 특정 영역에서 선언한다.
- 해당 영역에서만 사용할 수 있다.
- 사용하기 전에 반드시 초기화해야 한다.

## 5. 메서드(Method)

메서드는 서로 관련된 여러 문장을 하나로 묶은 것이다.

### 메서드의 기본 구조

```java
int add(int x, int y) {
    int result = x + y;
    return result;
}
```

| 구성 요소 | 설명 |
|---|---|
| `int` | 반환 타입 |
| `add` | 메서드 이름 |
| `int x, int y` | 매개변수 선언 |
| `int result = x + y;` | 메서드 구현부 |
| `return result;` | 반환값 |

### 반환 타입이 없는 메서드

반환값이 없는 메서드는 `void`를 사용한다.

```java
void print99danAll() {
    for (int i = 1; i <= 9; i++) {
        for (int j = 2; j <= 9; j++) {
            System.out.print(j + " * " + i + " = " + (j * i) + " ");
        }
        System.out.println();
    }
}
```

### 메서드 호출

```java
add(3, 6);
print99danAll();
```

- `add(3, 6)` : 매개변수에 3과 6을 전달하여 메서드 호출.
- `print99danAll()` : 구구단을 출력하는 메서드 호출.

### return문

- 메서드의 실행을 종료한다.
- 반환값이 있다면 호출한 곳으로 값을 돌려준다.
- 반환값의 타입은 메서드의 반환 타입과 일치해야 한다.

### 매개변수와 지역 변수

매개변수는 메서드 내부에서 사용하는 지역 변수이다.

```java
void method1(int x) {
    System.out.println(x);
}

void method2(int x) {
    System.out.println(x);
}
```

두 메서드의 `x`는 이름만 같을 뿐 서로 다른 변수이다.

## 6. JVM의 메모리 구조

JVM(Java Virtual Machine)은 Java 프로그램을 실행하는 가상 머신이다.

대표적인 메모리 영역은 다음과 같다.

| 영역 | 역할 | 주요 저장 대상 |
|---|---|---|
| Method Area | 클래스 정보 저장 | 클래스 정보, static 변수, 메서드 정보 |
| Call Stack | 메서드 실행 공간 | 스택 프레임, 지역 변수, 매개변수 |
| Heap | 객체 저장 공간 | 생성된 객체와 인스턴스 변수 |

### 메서드 호출에 따른 Call Stack 변화

다음 코드를 살펴보자.

```java
class CallStackEx {
    public static void main(String[] args) {
        firstMethod();
    }

    static void firstMethod() {
        secondMethod();
    }

    static void secondMethod() {
        System.out.println("secondMethod()");
    }
}
```

#### ① main() 실행

프로그램이 시작되면 `main()`의 스택 프레임이 생성된다.

```text
┌──────────────────┐
│      main()      │
└──────────────────┘
```

#### ② firstMethod() 호출

`main()`에서 `firstMethod()`를 호출하면 해당 메서드의 스택 프레임이 추가된다.

```text
┌──────────────────┐
│  firstMethod()   │
├──────────────────┤
│      main()      │
└──────────────────┘
```

#### ③ secondMethod() 호출

`firstMethod()`에서 `secondMethod()`를 호출하면 스택 프레임이 하나 더 추가된다.

```text
┌──────────────────┐
│  secondMethod()  │ ← 현재 실행 중
├──────────────────┤
│  firstMethod()   │
├──────────────────┤
│      main()      │
└──────────────────┘
```

#### ④ secondMethod() 종료

```java
System.out.println("secondMethod()");
```

메서드가 종료되면 해당 스택 프레임이 제거되고 호출한 `firstMethod()`로 돌아간다.

```text
┌──────────────────┐
│  firstMethod()   │ ← 실행 재개
├──────────────────┤
│      main()      │
└──────────────────┘
```

#### ⑤ firstMethod() 종료

`firstMethod()`가 종료되면 해당 스택 프레임이 제거되고 `main()`으로 돌아간다.

```text
┌──────────────────┐
│      main()      │ ← 실행 재개
└──────────────────┘
```

#### ⑥ main() 종료

`main()`의 실행이 끝나면 마지막 스택 프레임도 제거된다.

```text
┌──────────────────┐
│   빈 호출 스택     │
└──────────────────┘
```

프로그램 실행이 종료된다.

## 7. 기본형 매개변수와 참조형 매개변수

메서드에 값을 전달할 때 기본형과 참조형은 전달되는 값의 의미가 다르다.

### 기본형 매개변수

- 기본형 변수의 값이 복사되어 전달된다.
- 메서드 내부에서 값을 변경해도 원래 변수에는 영향을 주지 않는다.

### 참조형 매개변수

- 객체의 주소값이 복사되어 전달된다.
- 전달받은 참조값을 통해 객체의 인스턴스 변수를 변경할 수 있다.
- 참조변수 자체를 다른 객체의 주소로 바꾸더라도 호출한 쪽의 참조변수는 바뀌지 않는다.

## 8. 재귀 호출(Recursive Call)

재귀 호출은 메서드가 자기 자신을 다시 호출하는 것이다.

### 예시

```java
void method(int n) {
    if (n == 0) {
        return;
    }

    System.out.println(n);
    method(--n);
}
```

`method(3)`을 호출하면 다음과 같이 실행된다.

```text
3
2
1
```

### 재귀 호출의 특징

- 반복적인 작업을 논리적으로 간결하게 표현할 수 있다.
- 종료 조건이 반드시 필요하다.
- 종료 조건이 없으면 무한 호출이 발생하여 `StackOverflowError`가 발생할 수 있다.
- 반복문으로 대체할 수 있는 경우도 있다.

## 9. 클래스 메서드와 인스턴스 메서드

메서드는 `static` 여부에 따라 클래스 메서드와 인스턴스 메서드로 구분된다.

### 인스턴스 메서드

- 인스턴스가 필요한 메서드이다.
- 객체를 생성한 뒤 호출할 수 있다.
- 인스턴스 변수(iv)를 사용할 수 있다.

```java
class Student {
    String name;

    void printName() {
        System.out.println(name);
    }
}

Student s = new Student();
s.name = "한빈";
s.printName();
```

### 클래스 메서드

- `static` 키워드를 사용하는 메서드이다.
- 객체 생성 없이 클래스 이름으로 호출할 수 있다.
- 인스턴스 변수(iv)를 직접 사용할 수 없다.

```java
class Calculator {
    static int add(int a, int b) {
        return a + b;
    }
}

int result = Calculator.add(3, 5);
```

### 클래스 메서드와 인스턴스 메서드의 관계

- 클래스 메서드에서는 객체 생성 없이 인스턴스 메서드를 직접 호출할 수 없다.
- 인스턴스 메서드에서는 같은 객체의 다른 인스턴스 메서드를 직접 호출할 수 있다.
- 인스턴스 메서드에서도 클래스 메서드를 호출할 수 있다.

핵심은 클래스 메서드는 특정 객체의 인스턴스 변수에 접근할 수 없다는 것이다.

## 10. 메서드 오버로딩(Overloading)

오버로딩은 같은 이름의 메서드를 여러 개 정의하는 것이다.

### 오버로딩의 조건

1. 메서드 이름이 같아야 한다.
2. 매개변수의 개수 또는 타입이 달라야 한다.
3. 반환 타입은 오버로딩을 구분하는 기준이 아니다.

### 예시

```java
class Calculator {
    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }

    double add(double a, double b) {
        return a + b;
    }
}
```

매개변수의 개수나 타입에 따라 서로 다른 메서드가 호출된다.

### 가변인자(Varargs)

가변인자는 매개변수의 개수를 유동적으로 전달할 수 있도록 하는 문법이다.

```java
String concatenate(String... str) {
    String result = "";

    for (String s : str) {
        result += s;
    }

    return result;
}
```

- `String...`을 사용한다.
- 내부적으로 배열 형태로 처리된다.
- 가변인자는 매개변수 목록의 마지막에 위치해야 한다.

## 11. 생성자(Constructor)

생성자는 객체가 생성될 때 호출되며, 객체의 초기 상태를 설정하는 데 사용한다.

### 생성자의 특징

1. 생성자의 이름은 클래스 이름과 같다.
2. 반환 타입이 없다. (`void`도 작성하지 않는다.)
3. 객체 생성 시 자동으로 호출된다.

### 생성자의 종류

#### (1) 매개변수가 없는 생성자

```java
class Card {
    Card() {
        // 기본값으로 초기화
    }
}
```

#### (2) 매개변수가 있는 생성자

```java
class Card {
    String kind;
    int number;

    Card(String k, int num) {
        kind = k;
        number = num;
    }
}
```

객체를 생성하면서 원하는 값을 전달할 수 있다.

### 객체 초기화 방법

#### (1) 객체 생성 후 직접 값 대입

```java
Card c = new Card();
c.kind = "H";
c.number = 8;
```

#### (2) 생성하면서 값 전달

```java
Card c = new Card("H", 8);
```

### 객체 생성 과정

```java
Card c = new Card();
```

1. `new` 연산자에 의해 메모리에 Card 인스턴스가 생성된다.
2. 생성자 `Card()`가 호출되어 실행된다.
3. 생성이 완료된 인스턴스의 주소가 참조변수 `c`에 저장된다.

### 기본 생성자

기본 생성자는 매개변수가 없는 생성자를 의미한다.

```java
class Card {
    Card() {
    }
}
```

- 클래스에 생성자가 하나도 없으면 컴파일러가 기본 생성자를 자동으로 추가한다.
- 매개변수가 있는 생성자를 직접 작성하면 기본 생성자는 자동으로 추가되지 않는다.
- 따라서 필요하다면 기본 생성자를 직접 작성해야 한다.

### 매개변수가 있는 생성자

```java
class Car {
    String color;
    String gearType;
    int door;

    Car() {
    }

    Car(String c, String g, int d) {
        color = c;
        gearType = g;
        door = d;
    }
}
```

객체 생성 시 외부에서 전달받은 값으로 인스턴스 변수를 초기화할 수 있다.

### this()를 이용한 생성자 호출

같은 클래스의 다른 생성자를 호출할 때 `this()`를 사용한다.

```java
class Card {
    String kind;
    int number;

    Card() {
        this("SPADE", 1);
    }

    Card(String kind, int number) {
        this.kind = kind;
        this.number = number;
    }
}
```

- 생성자 이름 대신 `this()`를 사용한다.
- 같은 클래스의 다른 생성자를 호출한다.
- 반드시 생성자의 첫 번째 문장에서 호출해야 한다.

### this 참조변수

`this`는 현재 인스턴스 자신을 가리키는 참조변수이다.

```java
class Card {
    String kind;
    int number;

    Card(String kind, int number) {
        this.kind = kind;
        this.number = number;
    }
}
```

- `this.kind` : 인스턴스 변수
- `kind` : 매개변수

매개변수와 인스턴스 변수의 이름이 같을 때 `this`를 사용하여 구분한다.

매개변수와 인스턴스 변수의 이름이 다르면 `this`를 생략할 수 있다.

**`this`와 `this()`의 차이**

| 구분 | 의미 |
|---|---|
| `this` | 현재 인스턴스 자신을 가리키는 참조변수 |
| `this()` | 같은 클래스의 다른 생성자를 호출 |

## 12. 변수의 초기화

변수의 초기화란 변수를 선언하고 처음으로 값을 저장하는 것이다.

### 변수별 초기화 특징

| 변수 종류 | 초기화 특징 |
|---|---|
| 지역 변수(lv) | 자동 초기화되지 않으므로 사용 전에 직접 초기화해야 한다. |
| 인스턴스 변수(iv) | 선언 시 초기화하지 않으면 기본값으로 자동 초기화된다. |
| 클래스 변수(cv) | 선언 시 초기화하지 않으면 기본값으로 자동 초기화된다. |

### 기본 초기값

| 자료형 | 기본값 |
|---|---|
| 정수형 | `0` |
| 실수형 | `0.0` |
| boolean | `false` |
| char | `'\u0000'` |
| 참조형 | `null` |

### 초기화 예시

```java
class InitTest {
    int x;
    int y = x; // 가능

    void method() {
        int i;
        // int j = i; // 오류: 지역 변수 i가 초기화되지 않음
    }
}
```

인스턴스 변수는 자동 초기화되지만, 지역 변수는 자동 초기화되지 않는다.

## 13. 멤버 변수의 초기화 방법

멤버 변수(iv, cv)는 다음 세 가지 방법으로 초기화할 수 있다.

### (1) 명시적 초기화

변수 선언과 동시에 값을 대입하는 방법이다.

```java
class Car {
    int door = 4;
    String color = "White";
    static int count = 0;
}
```

간단한 초기화에 사용한다.

### (2) 생성자 사용

객체 생성 시 전달받은 값으로 인스턴스 변수를 초기화한다.

```java
class Car {
    String color;
    int door;

    Car(String color, int door) {
        this.color = color;
        this.door = door;
    }
}
```

객체마다 다른 초기값을 설정할 때 사용한다.

### (3) 초기화 블럭

초기화 블럭은 여러 초기화 작업을 수행할 때 사용할 수 있다.

**인스턴스 초기화 블럭**

```java
class Car {
    int door;

    {
        door = 4;
    }
}
```

- 인스턴스가 생성될 때 실행된다.
- 인스턴스 변수를 초기화하는 데 사용한다.

**클래스 초기화 블럭**

```java
class Car {
    static int count;

    static {
        count = 0;
    }
}
```

- 클래스가 메모리에 로딩될 때 한 번 실행된다.
- 클래스 변수를 초기화하는 데 사용한다.

### 멤버 변수 초기화 방법 정리

| 방법 | 사용 목적 |
|---|---|
| 명시적 초기화 | 간단한 초기값 설정 |
| 생성자 | 객체마다 다른 초기값 설정 |
| 인스턴스 초기화 블럭 | 인스턴스 변수의 복잡한 초기화 |
| 클래스 초기화 블럭 | 클래스 변수의 복잡한 초기화 |

### 초기화 순서

**클래스 변수**
1. 기본값
2. 명시적 초기화
3. 클래스 초기화 블럭

**인스턴스 변수**
1. 기본값
2. 명시적 초기화
3. 인스턴스 초기화 블럭
4. 생성자

## 핵심 정리

- **OOP**: 프로그램을 객체 단위로 구성하는 프로그래밍 방식.
- **클래스**: 객체를 생성하기 위한 설계도.
- **객체**: 클래스에 정의된 속성과 기능을 가진 실체.
- **인스턴스 변수**: 객체마다 독립적으로 존재하는 변수.
- **클래스 변수**: 모든 객체가 공유하는 변수.
- **지역 변수**: 메서드 내부 등 특정 영역에서 사용하는 변수.
- **메서드**: 관련된 여러 문장을 하나로 묶은 기능.
- **생성자**: 객체 생성 시 초기 상태를 설정하는 특별한 구성 요소.
- **this**: 현재 인스턴스 자신을 가리키는 참조변수.
- **this()**: 같은 클래스의 다른 생성자를 호출하는 문법.
- **오버로딩**: 같은 이름으로 매개변수 구성을 다르게 하여 여러 메서드를 정의하는 것.
- **JVM 메모리 구조**: Method Area, Call Stack, Heap으로 구분하여 이해한다.
